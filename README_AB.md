# A/B-тест рекламной кампании: реклама против PSA

Анализ A/B-теста маркетинговой кампании: проверяю, повышает ли рекламный баннер конверсию по сравнению с нейтральным объявлением (PSA), и оцениваю, какая часть конверсий обязана рекламе.

## Вопросы исследования

1. Была ли кампания успешной, то есть различается ли конверсия между группами статистически значимо?
2. Какая часть конверсий в рекламной группе может быть приписана рекламе?

## Данные

Датасет Marketing A/B Testing (Kaggle), файл `marketing_AB.csv`: 588 101 пользователь, каждый встречается один раз.

| Колонка | Описание |
|---|---|
| `user id` | идентификатор пользователя |
| `test group` | группа: `ad` (видели рекламу) или `psa` (видели нейтральное объявление) |
| `converted` | совершил ли пользователь конверсию (True / False) |
| `total ads` | сколько рекламных объявлений увидел пользователь |
| `most ads day` | день недели, когда увидел больше всего рекламы |
| `most ads hour` | час дня, когда увидел больше всего рекламы |

Размеры групп: `ad` 564 577 (96,0%), `psa` 23 524 (4,0%). Контроль намеренно небольшой, как описано в источнике данных.

## Методология

- **Гипотезы:** H₀ — конверсия в группах одинакова; H₁ — конверсии различаются. Уровень значимости α = 0,05.
- **Метрика:** доля пользователей, совершивших конверсию.
- **Тест:** двусторонний z-тест пропорций. Метрика бинарная, единица наблюдения пользователь, поэтому допущения теста выполняются.
- **Доверительный интервал** разницы долей: интервал Вальда, 95%.
- **Размер эффекта:** абсолютная разница (п.п.), относительный прирост (lift), дополнительные конверсии и доля конверсий, обязанная рекламе.

Проверки данных: все `user id` уникальны, пересечений между группами нет, соотношение групп соответствует заявленному 96/4.

## Результаты

| Показатель | Значение |
|---|---|
| Конверсия `ad` | 2,55% (14 423 из 564 577) |
| Конверсия `psa` | 1,79% (420 из 23 524) |
| Разница | +0,77 п.п. (95% ДИ: 0,60–0,94 п.п.) |
| Относительный прирост | +43% |
| z-статистика | 7,37 |
| p-value | ≈ 1,7 · 10⁻¹³ |
| Дополнительные конверсии от рекламы | ≈ 4 343 |
| Доля конверсий `ad`, обязанная рекламе | ≈ 30% |

Результат согласуется с проверкой через хи-квадрат (без поправки: √χ² = z), с поправкой Йейтса и точным тестом Фишера.

## Выводы

Конверсия в рекламной группе значимо выше, чем в контрольной: H₀ отвергается. Реклама дала около 4,3 тыс. дополнительных конверсий, то есть примерно 30% конверсий группы `ad`. Остальные ~70% произошли бы и без неё.

## Как считались дополнительные конверсии

```
дополнительные конверсии = (p_ad − p_psa) × n_ad
доля, обязанная рекламе   = (p_ad − p_psa) / p_ad
```

Расчёт предполагает, что без рекламы группа `ad` конвертировалась бы так же, как контроль.

## Ограничения

- Рандомизация принята по описанию датасета и не проверялась: колонки `total ads`, `most ads day`, `most ads hour` измерены после начала эксперимента и для такой проверки не подходят. По этой же причине они не использовались в основном анализе.
- Сравнение идёт с PSA, а не с отсутствием показа, поэтому оценивается эффект содержания баннера.
- В данных нет выручки и затрат на рекламу, поэтому денежный эффект не оценивался.
- Оценка дополнительных конверсий опирается на допущение, что PSA сам не влияет на конверсию.
