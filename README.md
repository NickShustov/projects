# Портфолио: анализ данных

Меня зовут Никита Шустов. В репозитории два аналитических проекта на Python: сегментация футбольных клубов по трансферной активности и A/B-тест рекламной кампании. В каждом проекте есть свой README с подробностями.

## Проекты

| Проект | Задача | Методы | Инструменты |
|---|---|---|---|
| [RFM-сегментация клубов топ-5 лиг](rfm-football-transfers/) | Разделить клубы на сегменты по тому, как давно, как часто и на какие суммы они покупают игроков | RFM-анализ, сегментация по правилам, анализ покупок и продаж | Python, pandas, DuckDB (SQL), seaborn |
| [A/B-тест рекламы против PSA](ab-test-ads-vs-psa/) | Проверить, повышает ли реклама конверсию, и оценить долю конверсий, обязанную рекламе | z-тест пропорций, доверительные интервалы, размер эффекта | Python, pandas, NumPy, SciPy |

## Коротко о результатах

**RFM-сегментация футбольных трансферов.** Данные Transfermarkt за сезоны 2015/16 – 2025/26. Расходы клубов топ-5 лиг сильно сконцентрированы: топ-10% клубов тратят около половины всех денег. Помимо классического RFM в сегментации учтены средний чек и соотношение продаж и покупок клуба.

**A/B-тест рекламной кампании.** Конверсия в группе с рекламой 2,55%, в контрольной (PSA) 1,79%: разница +0,77 п.п. (+43% относительно контроля), p ≈ 10⁻¹³. Примерно 30% конверсий рекламной группы обязаны рекламе.

## Что показывают проекты

- очистка данных и поиск проблем в источнике (например, задвоенные строки возврата из аренды)
- SQL и pandas для подготовки данных
- сегментация клиентов и проверка устойчивости результата
- проверка гипотез и оценка размера эффекта
- явное описание допущений и ограничений анализа
